# Dastarkhwan 🍽️

Dastarkhwan is a food ordering website built with React and Vite.

## Features
- Browse food items
- Responsive user interface
- Easy food ordering experience

## Technologies Used
- React.js
- Vite
- JavaScript
- CSS

## Run Locally

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
